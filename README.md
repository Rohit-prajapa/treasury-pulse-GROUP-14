# Treasury Pulse — Frontend

Dark navy React + Vite dashboard starter for the Treasury Pulse hackathon.

## Requirements
- Node.js (LTS recommended)
- npm

## Run in VS Code
1. Extract this ZIP.
2. Open the extracted `treasury-pulse-frontend` folder in VS Code.
3. Open Terminal → New Terminal.
4. Run:

```bash
npm install
npm run dev
```

5. Open the local URL printed by Vite (usually http://localhost:5173).

## Notes
- This starter uses illustrative synthetic data only.
- Forecast and scenario numbers are placeholders, not financial predictions.
- Backend API paths in `src/services/api.js` are proposed examples; coordinate them with your team.
